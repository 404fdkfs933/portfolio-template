## 2026-10-08 — restyled on karimrashid.com

- Steven asked for the template to be modelled on www.karimrashid.com. The content model (site.ts, content/projects, public/art, about.md) is unchanged; the whole visual layer is new.
- Home: full-screen portrait (`public/portrait.jpg`, placeholder generated by `scripts/make-samples.py`) with the name set huge and an arrow to About; then `WorkStrip`, a pinned section where vertical scroll drives one full-screen slide per featured series sideways (mouse + wide screen + no reduced motion; otherwise a swipe row); then `SeriesTiles`, a two-column grid of every series with piece count and giant title (an odd last tile goes full width).
- Header: signature-style name top-left (or `site.logo`), MENU button top-right opening a dark right-hand panel with WORK / ABOUT / CONTACT set huge, email and socials at the bottom. Escape and the scrim close it; body scroll locks.
- Series page: sticky left column (title, medium, year, summary, statement, All work), two-column image grid with captions, previous/next as two half-width tiles.
- About: portrait left, "01 ABOUT" in the accent colour with the `site.intro` opener; "02 Story" with `content/about.md` below. Contact: outlined CONTACT title, email in the accent, optional `site.address`. 404 in the same voice.
- Tokens: white / #f4f4f4 / #111 / accent #ff2d95. Fonts: Anton, Archivo, Caveat. Dark mode and next-themes removed (the design is light only); lucide-react no longer used.
- Removed: hero-ghost, printed-heading, project-bands, art-slider, project-card, theme-toggle, bits, motion.
- Checked at 1280 wide in Chrome: home strip, menu, series page, About, Contact. Not checked on a phone-sized viewport (the browser would not resize below its minimum); the swipe row is CSS only and should hold.
- Known: on a short viewport with a long series statement the left column is taller than the screen, so its tail scrolls under the floating signature at the end of the page. Real statements are short; left as is.
