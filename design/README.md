# design/

Working files worth keeping with the site: sketches, colour references, layout ideas, exported mockups. Anything here is versioned by git but never published.

- Keep individual files under 100 MB (GitHub's hard limit) and the folder under a few hundred MB in total.
- Full-resolution originals belong in `design/originals/`, which git ignores. Back those up somewhere else.
- Web-sized exports that appear on the site go in `public/art/<series>/`, not here.
